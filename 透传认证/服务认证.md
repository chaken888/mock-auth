## 概述
服务认证即接口平台调用第三方接口时需要的认证，该认证为第三方接口的认证。当前服务认证是配合动态表单配置使用的。可以通过配置表单和实现接口方便的进行认证的扩展  。
目前服务认证默认支持`BASIC认证`、`摘要认证`、`OAUTH2认证`、`OAUTH1认证`、`SOAP认证`、`BEARER_TOKEN认证`、`自定义键值认证`、`Groovy脚本认证`、`SAP认证`、`模拟身份认证`等方式认证。

| 字段名称 | 字段说明                                                     |
| -------- | ------------------------------------------------------------ |
| 创建模式 | 认证的创建模式，分为选择已有配置和自定义；选择已有配置时认证信息不能修改， 自定义时可以修改，且第一次保存时会在API治理策略-接口认证下对应的认证分类下新增数据，后续保存会更新认证信息 |
| 认证编码 | 选择已有配置时显示，选择当前租户下的在[API治理策略](local://hsop-document?doc_id=469484&doc_code=213646)界面维护的接口认证数据；自定义时认证编码由系统自动生成 |
| 认证名称 | 选择已有配置时不可编辑，由选择的数据自动带出；自定义时可编辑，对应API治理策略界面的配置名称字段，租户下唯一 |
