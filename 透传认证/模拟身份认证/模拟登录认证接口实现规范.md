## 接口规范

调用方通过接口平台调用第三方系统接口时，若第三方系统接口有认证鉴权则需要在接口平台上配置服务认证，如果想根据调用方的身份(例如用户名、手机号)动态模拟第三方系统的认证，则需要第三方系统提供模拟登录认证的接口。以下是接口规范：

| 接口地址     | 请求方法 | 媒体类型(MediaType) | 请求参数                                                     | 响应参数                                                     |
| ------------ | -------- | ------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| 由用户自定义 | POST/GET | application/json    | 由用户自定义，可以为query参数、header参数、body参数，要求可根据当前请求参数获取到唯一的认证token，例如{"username":"admin"} | 由用户自定义，但响应体中必须包含认证token，例如{"access_token":"03d5d97a-20c7"}，响应体中也可返回token的过期时间字段 |

同时为了保证接口的安全性接口平台会对请求数据按照约定的规则进行加签，第三方系统需根据约定的规则进行验签，增强接口安全性。

## 接口验签步骤

### 1、所有参数(请求body参数、公共请求参数)进行字典序排序（参数以key=value拼接，参数之间用&分隔符）

特别地请求body参数key为**authBodyParam**； 公共请求参数包含**timestamp**(请求时间戳)、**signType**(加签算法类型)，公共请求参数由接口平台自动传递到接口的请求头

示例数据：

POST请求-body传参：

```
authBodyParam={"username":"admin"}&signType=RSA&timestamp=1706600798268
```

GET请求-query传参：

```java
signType=RSA&timestamp=1706600798268&userName=admin
```

示例java代码：

```java
//获取请求头
String timestamp = request.getHeader("timestamp");
String signType = request.getHeader("signType");

Map<String, String> toSignMaps = new TreeMap<>();
toSignMaps.put("authBodyParam", requestBody);
toSignMaps.put("signType", signType);
toSignMaps.put("timestamp", timestamp);

StringBuilder stringBuilder = new StringBuilder();
for (Map.Entry<String, String> entry : toSignMaps.entrySet()) {
    stringBuilder.append(Optional.ofNullable(entry.getKey()).map(String::trim).orElse(""));
    stringBuilder.append("=");
    stringBuilder.append(Optional.ofNullable(entry.getValue()).map(String::trim).orElse(""));
    stringBuilder.append("&");
}
stringBuilder.deleteCharAt(stringBuilder.length() - 1);
return stringBuilder.toString();
```

### 2、将第1步生成的字符串按照utf-8编码

示例java代码：

```java
byte[] data = str.getBytes(StandardCharsets.UTF_8)
```

### 3、匹配加签算法

根据公共请求参数**signType**(加签算法类型)匹配对应的加签算法

示例java代码：

```java
String signAlgorithm;
if("RSA".equals(signType)){
    signAlgorithm = "SHA1WithRSA";
}else if("RSA2".equals(signType)){
    signAlgorithm = "SHA256WithRSA";
}else if("MD5".equals(signType)){
    signAlgorithm = "MD5withRSA";
}
```

### 4、使用公钥对第2步产生的数据与加签数据进行验签（使用第3步匹配的加签算法）

加签数据由接口平台传递到接口的请求头，参数名为sign

示例java代码：

```java
String sign = request.getHeader("sign");
public boolean verify(byte[] data, String publicKey, String sign, String signAlgorithm) {
    try {
        byte[] keyBytes = Base64.getDecoder().decode(publicKey);
        X509EncodedKeySpec keySpec = new X509EncodedKeySpec(keyBytes);
        KeyFactory keyFactory = KeyFactory.getInstance("RSA");
        PublicKey publicK = keyFactory.generatePublic(keySpec);
        Signature signature = Signature.getInstance(signAlgorithm);
        signature.initVerify(publicK);
        signature.update(data);
        return signature.verify(Base64.getDecoder().decode(sign));
    } catch (Exception e) {
        e.printStackTrace();
        return false;
    }
}
```

### 5、检查时间戳timestamp(可选)

假如请求约定时间戳误差范围为5分钟，也就是300秒，根据接收到的时间戳1706600798268计算出时间戳范围

```
1706600798268-300  ~~  1706600798268+300
```

如果获取的服务器本地时间戳不在范围内，则拒绝访问
